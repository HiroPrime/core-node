# Workflow: Iteration Loops

Goal: fewer than **3 passes** from draft → shippable direction.

---

## Loop A — Product / Copy (Director Gem)

```
Pass 1: Generate (brief or copy)
Pass 2: Critique (/critique) + your KEEP/TWIST/SCRAP
Pass 3: Final polish only (cut words / sharpen CTA / credit fix)
STOP. Ship to art or code.
```

If still weak after Pass 3 → **SCRAP structure**, don’t micro-edit forever.

---

## Loop B — Visual (Art Director Gem)

```
Pass 1: Generate with STYLE LOCK + BASICHIRO/CORE_NODE lock
Pass 2: Consistency repair prompt (fix drifts only)
Pass 3: Crop/lighting/framing tweak OR accept
STOP. Do not redesign the logo mid-campaign.
```

**Hard stop rule:** if Pass 2 still breaks identity anchors → regenerate from Pass 1 with stricter negative prompt.

---

## Feedback language cheat sheet

| You say | Meaning |
|---------|---------|
| `TWIST: more arcade` | Galaga / colorful universe |
| `TWIST: more command` | Orbitron / console voice |
| `TWIST: less SaaS` | Kill portfolio dashboard vibes |
| `FIX LOCK: logo` | Orbital orange mark repair |
| `FIX LOCK: dark only` | Kill light mode drift |
| `ENERGY: +nebula` | More color in the void |
| `ENERGY: -dashboard` | Remove KPI soup |
| `CREDIT FIX` | Restore By BASICHIRO |
| `SHIP IT` | End loop |

Ask: “What would a senior product designer cut from this first viewport?”  
Ask: “Where does this bleed into Prime Portal or Grimm Fracture?”  
Ask: “Is the logo still the hero signal if we remove the nav?”
