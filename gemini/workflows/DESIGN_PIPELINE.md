# Workflow: Design Pipeline (Speed)

Optimized for frequent UI/copy/direction drops with Gemini assistance — then handoff to code (Cursor).

## Cadence options

| Mode | Brief | Visual | Ship to code |
|------|-------|--------|--------------|
| **Sprint** | 3 screens / weekend | 1 key visual / day | Continuous |
| **Steady** | 1 feature brief / day | Prompt pack as needed | PR-sized chunks |
| **Arc burst** | Full constellation pass first | Batch space + logo frames | Weekly theme drop |

Pick one; don’t mix mid-feature.

---

## Pipeline stages

### 0) Canon load (once)
Gem knowledge = bible + style + BASICHIRO + systems.

### 1) Brief lock
`/ideas` → KEEP → `/brief` → paste into issue/PR or `systems/` notes.

### 2) Direction factory
For each surface:
1. `/copy` for strings  
2. KEEP/TWIST once  
3. `/prompt` or `/space` for visual  
4. Generate with style + logo locks  
5. Consistency checklist (`STYLE_GUIDE.md`)  
6. Hand to Cursor/code with acceptance criteria  

### 3) Buffer
Never design only what you’re coding today. Keep **+1 screen brief** ahead.

### 4) Changelog
After each ship, note:

```
## Direction log
- YYYY-MM-DD: shipped [surface]
- Drift caught: …
- Lock updates: none / [file]
```
