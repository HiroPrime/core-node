# Workflow: Idea Sprint (10–20 min)

Use when you need options fast — home UX, map moments, sister-node framing, or social posts.

## Setup

Gem: **Core Node Director**  
Mode: `/ideas`

## Sprint card (copy)

```
IDEA SPRINT
Constraint: stay inside PRODUCT_BIBLE + STYLE_GUIDE + active systems/
Axis to explore: [home hero / map navigation / Explore CTA / arcade space / BASICHIRO credit / sister node card]
Quantity: 8
Timebox: one reply, then I feedback
```

## Feedback protocol (immediate iteration)

Reply with only one of:

- `KEEP #3` — develop into `/brief`  
- `TWIST #3` + note (`more arcade` / `less SaaS` / `stronger orange`)  
- `SCRAP` — new 8, avoid X  
- `HYBRID 2+5` — merge  

Gemini must regenerate in ≤1 reply using that instruction.

## Play modes (rotate)

1. **First drop** — user lands on `/` cold  
2. **Map scroll** — planet-to-planet discovery  
3. **Arcade first** — space spectacle before copy  
4. **Credit clear** — BASICHIRO always readable  
5. **Sister respect** — no identity bleed  
6. **Opposite day** — invert obvious portfolio patterns; keep canon  

## Promotion rule

Nothing from a sprint is canon until you say:

`LOCK: put this into gemini/systems/[FILE].md under [section]`

Then ask Gemini for `/lock` paste-ready markdown.
