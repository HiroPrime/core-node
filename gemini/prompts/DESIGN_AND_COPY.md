# Design & Copy Prompt Pack

Paste into the **Core Node Director** Gem after knowledge files are loaded.

---

## `/ideas` — Idea sprint

```
/ideas
Context: Core Node constellation hub (PRODUCT_BIBLE + STYLE_GUIDE).
Goal: [e.g. home hero tweak / map affordance / sister node card / social BIP]
Generate 8 options. For each: 1-line pitch, why it fits canon, drift risk, ship-speed 1–5.
Rank top 3. Recommend 1. End with KEEP / TWIST / SCRAP.
Label all as DRAFT.
```

---

## `/brief` — One-screen brief

```
/brief
Screen: [home hero / signal section / map details / linked planets list]
Audience: first-time visitor / returning explorer
Job-to-be-done: …
Constraints: dark arcade void, Nexus orange, By BASICHIRO, no ship, no Population soup if HUD hidden.
Deliver:
1) One-sentence visual thesis
2) Hierarchy (brand → primary action → secondary)
3) Component list
4) Copy deck (all strings)
5) Success metric
```

---

## `/copy` — UI strings

```
/copy
Surface: [home / map]
Include: status labels, CTAs, footer, hint text (Scroll or tap arrows).
Voice: command console × constellation wonder. No generic SaaS.
Use Mass not Level. Credit By BASICHIRO where entry surfaces require it.
```

---

## `/critique`

```
/critique
Review the last proposal against PRODUCT_BIBLE + STYLE_GUIDE + CONSTELLATION.
Call out: brand drift, sister-node bleed, dashboard soup, missing BASICHIRO credit, light-mode risk.
End with KEEP / TWIST / SCRAP recommendation.
```

---

## `/constellation`

```
/constellation
Idea: …
Map how it appears on Core Node vs each sister world without identity bleed.
Call out any status/name/color conflicts with systems/CONSTELLATION.md.
```
